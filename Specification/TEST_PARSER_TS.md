# Руководство по использованию теста JsonWSM

## Обзор

В этом руководстве объясняется, как запустить и использовать набор тестов для парсера JSON JsonWSM.

## Запуск тестов

### Предварительные условия

- Совместимый с C++17 компилятор
- Make
- PowerShell (для скрипта сборки)

### Сборка и запуск тестов

1. Перейдите в каталог проекта
2. Выполните следующие команды:

# Запуск тестов
./test.ps1 # Запуск всех тестов
./test.ps1 struct # Запуск проверки структуры
./test.ps1 types # Запуск проверки типов данных
./test.ps1 base # Запуск проверки вложенных объектов
./test.ps1 invalid # Запуск проверки недопустимого JSON
./test.ps1 C:/TestPath/test.json # Запуск файла текущего теста
```

## Тестовые файлы

Набор тестов включает несколько файлов JSON в каталоге `.\Test\Json`:

### Тесты структуры
- `test_struct.json` - Тестирует базовую структуру и форматирование JSON
- `test_invalid.json` - Тестирует обработку ошибок для некорректного JSON

### Тесты типов данных
- `test_types.json` - Тестирует все поддерживаемые типы данных
- `test_float.json` - Тестирует тип float с ограничениями точности
- `test_numeric.json` - Тестирует числовой тип с ограничениями точности

### Тесты вложенных структур
- `test_struct.json` - Тестирует вложенные объекты и массивы
- `test_base.json` - Тестирует сложные вложенные структуры

### Особые случаи
- `test_simbol.json` - Тестирует обработку символов UTF-8

## Тестовый вывод

При запуске исполняемого файла теста он:

1. Отобразит содержимое входного файла JSON
2. Проанализирует JSON и покажет структуру
3. Выведет дополнительную информацию об объекте JSON:

- Размер корневого объекта
- Является ли корневой объект пустым
- Список полей в корневой объект
- Правильно ли проанализирован JSON (isCorrectly())

## Пример тестового вывода

```bash
Входной JSON: { "name": "John", "age": 30, "active": true }

Проанализированная структура JSON:
name (string): "John"
age (integer): 30
active (boolean): true

Дополнительная информация:
Размер корневого объекта: 3
Корневой объект пустой: нет
Поля корневого объекта: name, age, active
Проанализировано правильно: да
```

## Создание пользовательских тестов

Чтобы создать собственные тестовые случаи:

1. Создайте новый файл JSON в каталоге `Test` с описательным именем:
- `test_<category>.json` для тестов категорий
- `test_<specific>.json` для тестов конкретных функций

2. Добавьте комментарий в начало файла, описывающий, что делает тест:
```json
# Тестовый файл для определенной функции
# Этот тест проверяет...
{
"test": "data"
}
```

3. Запустите тест:
```bash
./test.ps1 <category>
```

## Устранение неполадок

Если у вас возникли проблемы:

1. Убедитесь, что установлены все необходимые компоненты
2. Проверьте, что файл JSON действителен
3. Проверьте, что путь к файлу правильный
4. Проверьте наличие ошибок компиляции в выходных данных сборки
5. Используйте метод isCorrectly() для проверки структуры JSON
