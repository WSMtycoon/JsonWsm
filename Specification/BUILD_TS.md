Запуск сборки проекта запускается чеер комманду строку powershell.

.\Source Папка ресурсов проекта.
.\Test\Source Папка ресуров тестов.
.\Utils\Source Папка ресурсов утилит. 

.\bin папка сборки тестов запускаемых через коммандную строку.
.\lib папка расположения библиотек *.a которые можно включать в код.
.\Object папка расположения объектных файлов сборки.

Cистема сборки поддерживает следующие команды:
make - Target lib - сборка парсера и утилит в библиотеку
make - Target parser - сборка только парсера в объектные файлы 
make - Target utils - сборка только утилит в объектные файлы
make - Target test - сборка только тестов без пререзборки проекта
make - Target all - сборка всего проекта
make - Target clean - очистка всех веременных файлов сборки.

Версия -std=C++17

Сборка тестов - собирается 2 файла тестов. 

test_struct.cpp - проверяет работу парсера по уже готовой структуре Json. struct.exe 
test_parser.cpp - проверяет работу парсера по структурам задаваемым из параметров коммандной строки. parser.exe

Учитывать что при сборке проекта нужно добавлять файлы которые имеют только заголовочный файл без файла ресуров.
