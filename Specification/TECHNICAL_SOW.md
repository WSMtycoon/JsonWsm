# Техническая спецификация JsonParser Ru.

## Обзор проекта
JsonParser — это библиотека C++, разработанная для анализа и обработки структур данных JSON. 
Она обеспечивает надежный и типобезопасный способ работы с данными JSON, поддерживая различные типы данных и операции.

## Основные компоненты

### 1. Класс JsonParser
Основной класс, который обрабатывает анализ JSON и доступ к данным.

#### Основные характеристики:
- Анализ строк JSON
- Типобезопасный доступ к данным
- Навигация на основе пути
- Возможности обхода
- Поддержка вложенных структур

#### Основные методы:
- `JsonParser(const std::string& jsonStr)` - Конструктор со строкой JSON
- `Parser(const std::string& jsonStr)` - Парсинг строки JSON
- `isCorrectlyParsed()` - Проверка корректности парсинга
- `getType(const std::string& key)` - Получение типа значения по указанному пути
- `getValue(const std::string& key)` - Получение значения по указанному пути
- `getFields()` - Получение всех полей корневого объекта
- `size()` - Получение размера корневого объекта
- `empty()` - Проверка на пустой корневой объект
- `operator[](const std::string& key)` - Доступ к полям объекта
- `operator[](size_t index)` - Доступ к элементам массива

#### Доступ к вложенным структурам:
```cpp
// Доступ к вложенным объектам
auto value = parser["user"]["profile"]["name"];

// Доступ к элементам массива
auto item = parser["items"][0]["details"]["price"];

// Комбинированный доступ
auto nested = parser["mixed_structures"][0]["object"]["nested_array"][0][1];
```

### 2. Класс JsonValue
Представляет одно значение JSON с информацией о типе.

#### Поддерживаемые типы:
- `EMPTY` - Пустые значения (например, "key": )
- `BOOL` - Булевы значения
- `INT` - Целочисленные значения
- `LONG` - Длинные целочисленные значения (с суффиксом l)
- `FLOAT` - Плавающая точка одинарной точности (с суффиксом f)
- `DOUBLE` - Плавающая точка двойной точности
- `STRING` - Строковые значения
- `ARRAY` - Массивы JSON
- `OBJECT` - Объекты JSON
- `NULL_TYPE` - Значение типа Null

#### Методы класса:
- `empty()` - Проверка наличия значения
- `size()` - возвращает длину объектов и массивов, если значение простое возвращает -1
- `getType()` - возвращает тип значения
- `hasField(const std::string& key)` - проверка наличия поля в объекте
- `getFields()` - получение списка полей объекта
- `getValueString()` - возвращает значение в строковом формате для простых типов.
- `getJsonString()` - возвращает значение в строковом формате в кавычках для простых типов или блок JSON со всеми вложенными структурами.

#### Методы проверки типа:
- `isEmpty()` - проверка на пустое значение
- `isBool()` - проверка на булево значение
- `isInt()` - проверка на целое число
- `isLong()` - проверка на длинное целое число
- `isFloat()` - проверка на float
- `isDouble()` - проверка на double
- `isString()` - проверка на строку
- `isArray()` - проверка на массив
- `isObject()` - проверка на объект
- `isNull()` - проверка на null

- `isNumeric()` - проверка на числовое значение
- `isDecimal()` - проверка на значение с плавающий точкой
- `isVariant()` - проверка на простой тип
- `isBlock()` - проверка на блочный тип (массив или объект)

#### Геттеры типизированных значений:
Все геттеры возвращают std::optional для безопасного доступа к значениям:
- `getBool()` - получение булева значения (std::optional<bool>)
- `getInt()` - получение целого числа (std::optional<int>)
- `getLong()` - получение длинного целого числа (std::optional<long>)
- `getFloat()` - получение float (std::optional<float>)
- `getDouble()` - получение double (std::optional<double>)
- `getString()` - получение строки (std::optional<std::string>)
- `getArray()` - получение массива (std::shared_ptr<JsonArray>)
- `getObject()` - получение объекта (std::shared_ptr<JsonObject>)

Пример использования геттеров с std::optional:
```cpp
JsonParser parser(R"({
    "number": 123l,
    "optional_field": null
})");

if (parser.isCorrectlyParsed()) {
    // Безопасное получение значения
    if (auto longValue = parser["number"].getLong()) {
        // Значение существует и доступно через *longValue
        std::cout << "Long value: " << *longValue << std::endl;
    }

    // Проверка на null или отсутствующее значение
    if (!parser["optional_field"].getString()) {
        std::cout << "Field is null or doesn't exist" << std::endl;
    }
}
```

### 3. Блоковые структуры

#### 3.1 Класс JsonArray
Обрабатывает операции с массивами JSON.

##### Возможности:
- Доступ к элементам массива через operator[]
- Получение размера массива
- Проверка типа элементов
- Итерация по элементам

#### 3.2 Класс JsonObject
Управляет операциями с объектами JSON.

##### Возможности:
- Доступ к полям через operator[]
- Получение списка полей
- Проверка наличия полей
- Итерация по полям

##### Особенности:
- Общая функциональность для блочных структур
- Управление типами
- Операции с блоками

## Примеры использования

### Базовый парсинг
```cpp
JsonParser parser("{\"key\": \"value\"}");
if (parser.isCorrectlyParsed()) {
    auto value = parser["key"].getString();
    // value будет содержать "value"
}
```

## Обработка ошибок
- Типобезопасный доступ с использованием std::optional
- Проверка парсинга через isCorrectlyParsed()
- Обработка значений NULL и EMPTY
- Проверка существования полей через hasField()

## Соображения производительности
- Эффективный парсинг строк
- Использование интеллектуальных указателей для управления памятью
- Минимальное копирование данных
- Оптимизированный доступ к вложенным структурам

## Зависимости
- C++17 или более поздние версии
- Компоненты стандартной библиотеки:
  - std::string
  - std::variant
  - std::optional
  - std::shared_ptr
  - std::vector
  - std::map

## Ограничения
- Нет поддержки пользовательских числовых форматов
- Нет поддержки комментариев в JSON
- Все числовые значения с плавающей точкой должны иметь суффикс f для float
- Длинные целые числа должны иметь суффикс l для типа LONG

## Лучшие практики
1. Всегда проверяйте успешность парсинга с помощью isCorrectlyParsed()
2. Используйте проверку типов перед доступом к значению
3. Обрабатывайте необязательные значения соответствующим образом
4. Проверяйте существование полей перед доступом
5. Используйте правильные геттеры для каждого типа данных
6. Обрабатывайте пустые значения (EMPTY) и null значения отдельно
7. Всегда проверяйте результат геттеров через std::optional перед использованием значений
8. Используйте суффиксы l и f для явного указания типов LONG и FLOAT соответственно
